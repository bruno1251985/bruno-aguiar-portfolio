# Bruno Aguiar — Portfolio

Personal portfolio website for Bruno Aguiar, Junior Software Developer.

## Preview locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a public repository named `bruno-aguiar-portfolio`.
2. Upload `index.html` and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.

Expected URL: `https://bruno1251985.github.io/bruno-aguiar-portfolio/`
